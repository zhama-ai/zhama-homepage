# 首页行业面板与任务入口间距

日期：2026-11-15。内部研究与验证记录。

## 依据与采用范围

复用同日已实际阅读并记录的[行业方案布局研究](./home-industry-value-layout_V1.0.md)及其腾讯云第一方来源 https://cloud.tencent.com/solution/frm ：保留行业切换、业务痛点、解决方案与业务价值分组。该来源只用于信息层级判断，不新增行业业务口径或产品能力。

本次按用户截图调整已确认面板的纵向比例，保留外框、内容宽度与右下行业背景；不采用此前被用户否定的开放式或左右重排方案。三项业务价值在桌面改为图标、标题、正文纵向排列，借助内容结构增加高度，不设置固定高度或裁切长文案。800px 以下保留紧凑排布，600px 以下保留图标与标题横排。

任务入口按用户后续反馈撤去顶部四端及底部应用的附加底框，保留品牌原色。复用现有微信、飞书 SVG，以及 QQ、企业微信、钉钉透明 PNG；钉钉应用商店图标本身带有模糊浅蓝圆角边，现有透明原标无该边。输入区取消轻微透视变换，保留既有文字输入、任务流转动效和周期。

六个应用中心横坐标改为32、112、192、272、352、432，图标宽度保持56，净间距从约11增至24；图标中心下移至478，连接线与名称同步留白。新源文件为workspace-input-scene_V1.29.svg，历史版本保留。
