# 央国企解决方案业务重构底稿 V1.1

核对日期：2026-11-15（Asia/Shanghai）

## 业务主线

本版将首页与内页统一为“经营偏差穿透到项目，履约整改落实到责任”。三节直接使用集团、单位、项目、条款、响应证据与责任台账的业务关系，不再照搬银行式“知识库—系统连接—项目会话”结构。

| 三项价值 | 业务机制 | TeGo 承接 | 人员确认节点 |
| --- | --- | --- | --- |
| 经营偏差穿透单位项目 | 集团指标和预算口径下钻到单位及项目执行，差异对应收入回款、费用投入与项目变化，再接原因、责任和协调事项 | 差异穿透、原因关联、单位项目责任事项、经营会议材料 | 管理者审议和责任岗位接续督办 |
| 招采要求对应响应证据 | 资格、技术、商务要求拆项，逐项映射响应位置和证明材料；发现未覆盖、缺项和冲突 | 审查响应矩阵、条款与证据回查、缺项完善事项 | 专业复核、评审定标和投标承诺 |
| 履约整改形成责任闭环 | 合同里程碑和目标成本对照进展与实际记录；整改要求连接责任、时限、反馈证据与专业复核 | 履约节点台账、成本差异依据、整改责任与反馈对照 | 项目岗位跟进、专业复核和正式销号 |

首页 pain、value、三 benefits 与内页 features 同序同步。六岗位为集团经营、招采审查、投标响应、履约跟进、成本分析和隐患整改；全部岗位的过程、成果和价值均按业务重写，中英文同步。

## 独立视觉设计

文件：`src/features/solutions/state-owned/SolutionVisual.astro`。

- index = -1：集团目标分到所属单位和重点项目，分别接 TeGo 经营分析与履约跟进，招采核对横向承接资格、技术商务和响应证据，最终接专业岗位协调。
- index = 0：预算偏差责任树。集团预算执行分支到单位经营与项目成本，再下钻到原因叶节点和责任协调事项，接经营会议审议和后续督办。
- index = 1：招采响应矩阵。资格、技术、商务三类要求与响应证明、核对重点逐行对应；未覆盖、缺失和冲突回查条款证据后进入专业复核。
- index = 2：里程碑、成本、EHS整改三条履约轨道。各轨道呈现基准、进展和差异或反馈，再接具体岗位；证据台账串起下一步责任行动和复核。

四图采用二维业务图，暖金仅强调责任、判断与复核节点；蓝黑板面保持轻薄柔影，无实体硬件或三维材质。与政务的双通道、材料包和泳道不同，也不沿用通用工作台或三个系统接入框。所有业务文本为可读 DOM 文本；容器查询独立重排中文和英文，没有整体缩小图片。无虚构客户、人物、金额、效率、骨架条、页面顶部装饰横线、来源脚注或泛化免责声明。

## 产品能力核对

知识库、引用、技能、MCP/RESTful API/数据库、授权招投标和EHS插件、定时任务、专业子任务、项目版本、LDAP/OIDC及业务委托、私有化和本地模型均按本仓库已确认能力承接。数据接口作为按项目授权的接入方式，不声称已接通具体央企系统，不承诺跨系统权限自动继承。

旧 workbench 与 visual 字段仅暂留供根代理统一迁移，本版可见视觉不读取旧通用工作台对象。专业职责自然保留在业务正文和复核节点，不额外添加解释性小字。
