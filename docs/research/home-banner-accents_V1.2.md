# 首页三屏配色与原稿保真修复

日期：2026-11-16。

本记录取代 V1.1 中的原生重排实施方案。用户拒绝该方案改变已认可的效果；相关重排组件和布局均已回退，本轮不采用。

## 保留范围

第一、三屏只更新已确认的类别与关键数字配色，不修改布局、字号、透视或动画时间。第一屏与用户确认的 `home-workspace-accents_V1.2/comparison_V1.2.html` 对照；第三屏采用同组青、蓝紫、珊瑚点缀，完成保持薄荷，异常保持琥珀，分时柱状图保留同一青蓝色系和真实峰值。

第二屏沿用 V1.5 的完整业务 DOM、字号、间距、位置和 GSAP 时间轴。V1.6 原稿仅在 CSS 末尾增加局部配色；中英文 DOM 和时间轴与 V1.5 逐字相同。保留 1600×1000 逻辑画布、原裁切比例、桌面左向透视和 18 秒循环。

## 实际显示与采用依据

源帧及解码原像素清晰，不等于网页最终显示清晰。桌面 1280×720、DPR 2 实际检查中，第二屏舞台约 715×460，原视频为 3200×2000；15px 源稿说明文字最终仅约 7.3 CSS px。用户拒绝通过重排或改变字号修复，因此保持原稿尺寸，以浏览器直接绘制原稿文字和图形，减少视频编码与位图再次采样。

复用本轮已实际阅读的第一方资料：

- [ECharts 样式手册](https://echarts.apache.org/handbook/en/concepts/style/)，访问日期 2026-11-16。采用按类别维护色板与局部样式，避免整图滤镜；该资料不证明产品业务能力。
- [MDN foreignObject](https://developer.mozilla.org/en-US/docs/Web/SVG/Reference/Element/foreignObject)，访问日期 2026-11-16。采用 SVG 中的 XHTML 内容，保留原稿逻辑画布；`preserveAspectRatio="none"` 对齐原视频的独立宽高映射。
- [MDN object-fit](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/object-fit)，访问日期 2026-11-16。确认原 `fill` 的非等比映射。本轮为保真保留该映射，不将删除透视或调整比例当作修复。
- [MDN will-change](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/will-change) 及 [Chrome 合成层栅格化说明](https://developer.chrome.com/blog/re-rastering-composite)，访问日期 2026-11-16。用于分析合成与采样风险，不据此宣称所有浏览器都能消除锯齿。此次保留既有轮播效果，不再追加合成层重构。

## 实现边界

原 V1.6 CSS、DOM 和 GSAP 直接导入隔离的 iframe srcdoc，SVG foreignObject 只负责映射画布。iframe 隔离原稿全局选择器与时间轴，避免影响第一、三屏。外层保留原舞台尺寸与裁切；HTML 文档使用标准模式，并对齐父页 dark color-scheme，避免透明画布被浏览器垫成灰白色。

仅第二屏激活并可见时加载源文档。字体与时间轴准备完成后重新检查当前轮播状态，再显示动画，避免迟到的加载恢复已切离的画面。进入、离开、滚出、返回与减弱动态设置分别由宿主桥接处理；暂停保留局部时间，减弱动态显示第 15 秒完整成果。轮播保持整页左右滑动与既有交互。

保留既有静态海报作为未就绪与失败回退，退出当前网页的视频播放链。已生成的视频和历史预览保留，不将其删除或覆盖。

实际首页第二屏检查记录与截图位于 `output/previews/banner-preserved-final_V1.0/`。记录包含标准模式、字体就绪、原透视矩阵、715×460 舞台、透明背景、海报退出、脚本与请求错误检查。桥接单元测试验证懒加载、异步就绪、切离、暂停续播、状态隔离、减弱动态、消息来源与销毁。

上述属于源码、浏览器、自动化和 AI 视觉检查，不冒充真人可用性测试。保持原信息密度意味着窄屏细字仍小；不承诺所有屏幕和浏览器完全没有锯齿。企业部署区块属于其他并行编辑，不纳入本轮提交。

发布校验发现繁体转换器重新序列化 inline JSON 时丢失 `<` 转义，内嵌原稿的 `</script>` 被当作宿主脚本结束，造成重复标题与 ID。已在繁体生成程序统一安全序列化两类 inline JSON，并增加实际 HTML 解析回归测试，保留原稿字符串语义且防止内嵌文档泄漏到外层页面。简体、英文构建文档也逐字核对了原稿、透明 dark wrapper、GSAP 本地资源与 runtime。

最终 4350 的英文实页、手机及补充生命周期视觉检查未完成：本轮 IAB 控制连接连续超时，原生 Chrome 后续出现其他操作者的导航，已停止争用。此前 4351 中文桌面与独立中英运行记录有效；自动化桥接测试不能替代这些未完成的实际页面检查。
