# 首页空间层级修正

访问与验证日期：2026-11-15。

## 采用依据

- https://linear.app/now/how-we-redesigned-the-linear-ui ：已实际阅读。采用深色中性表面、少量强调色和清晰明暗层级，降低整屏蓝色界面的噪声；保留本项目已确认的布局与业务内容。
- https://fluent2.microsoft.design/elevation ：已实际阅读。采用同向关键阴影与柔和环境阴影表达距离。适用于界面局部前后关系，不据此增加厚重物体或硬件底座。

## 最终处理

- 第一屏降低标题栏亮度，选中员工与首项指标轻微前移。结论区只在工作台内部抬升：放大1.025倍、上移4px，保留左右与底部边距。移动端取消放大。轮播内部预留64px绘制空间，避免阴影被底部截断；不改变区块间距。补齐701–1100px工作台内容缩放，修复平板溢出。
- 第二屏以相同方向的小幅位移、边缘对比和阴影突出员工身份、系统来源、执行步骤及成果指标。中英文18秒时序与原有语音输入、转写、执行和交付动作保持。网站使用V1.3成套WebM与海报。
- 第三屏保留原内容、四个场景与20.8秒时序，改为开放式身份及时间线，当前任务、成果与送达回执形成层级；与前两屏的完整工作台和执行界面区分。
- 多端图区分底层与三个前景面，保留原矢量文字与头像。输入框与员工行中心对齐，员工行左右边距相同，成果区保持规整网格。上下漏斗连接输入框新边缘；原动画时长和相位未变。
- 行业方案缩小标题、正文、标签和价值条目字号，不更改已确认文案与交互。

## 实际验证

- Astro构建96页；238组响应式图片；55页繁体静态页面；发布输出剔除284项未引用历史素材。
- Astro检查135个文件，0错误、0警告、0提示。现有动效与成果测试11项通过。
- 最终站点检查17,855项：142个普通页面、27个重定向、13,415个本地引用、251个锚点，失败为空。
- 浏览器实际检查390、701、1024、1101、1280、1440px宽度下首屏无横向溢出，结论区底部位于工作台内。1280px下底部余量约9.60px，右侧约9.53px。
- 多端图1280px下输入框与员工行中心差约0.03px，成果组无旋转。最终漏斗接点已在1280px与390px实际检查，手机页面宽度为390px、没有横向滚动。
- 中文执行视频实际加载V1.3，1600×1000、18秒、readyState 4；激活播放，离屏暂停，重新进入恢复。第三屏送达回执在桌面和手机内完整显示；五个行业Tab均可切换且各有三个业务价值条目。
- 以上属于源码检查、自动化检查与浏览器运行检查；未进行真人可用性测试。

## 可编辑动效源码

`output/motion/task-execution_V1.3`与`output/motion/task-execution-en_V1.3`保存当前HTML、时间轴、GSAP与HyperFrames配置。页面播放最终媒体不依赖HyperFrames或本机字体。

重新渲染前，分别在两个项目内创建`assets/fonts/`，将macOS字体`/System/Library/Fonts/Hiragino Sans GB.ttc`复制为`assets/fonts/tego-cjk.ttc`。字体不重复纳入仓库。随后在项目内执行`npm run check`与`npm run render`；脚本固定使用HyperFrames 0.9.52。渲染输出使用新的版本文件名，保留已有媒体。

多端前景提取源码为`output/imagegen/lift-anywhere-foreground_V1.19.mjs`，依赖同目录已保留的`anywhere-workspace-depth_V1.18.png`及仓库内V1.17矢量文字。接线调整源码为`output/imagegen/reconnect-anywhere-inputs_V1.20.mjs`。脚本拒绝覆盖已有输出。
