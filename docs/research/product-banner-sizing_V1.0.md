# 产品能力页首屏尺寸统一

日期：2026-11-22（Asia/Shanghai）。范围：六个产品功能页首屏，保留正文、配图内容和背景。

用户指出岗位数字员工页右图过大、文字受到挤压，并要求六页配图尺寸一致。实际浏览器测量（1379px 视口）：岗位数字员工配图约 878×511px，多 Agent 640×436px，业务连接 734×457px，协作 670×463px，知识 670×366px，治理 670×394px。各页独立分栏和尺寸上限造成不一致。

本轮复用 capability-visual-directions_V1.2.md 的第一方产品构图研究，补读以下 CSS 机制来源：

- https://developer.mozilla.org/en-US/docs/Web/CSS/aspect-ratio ：已读取比例与自动尺寸计算说明。采用固定比例展示区域；单独指定比例不能保证内部 HTML 配图保持比例，因此配合实际内容尺寸测量。
- https://developer.mozilla.org/en-US/docs/Web/CSS/transform-function/scale ：已读取均匀缩放与坐标说明。采用同一缩放系数保留比例，不分别压缩宽高，不使用缩放动画。

实施：共享 1220px 首屏容器、等宽图文两列与 64px 间距；配图区域统一上限 600×420px，按自然尺寸等比容纳配图；通常使用 640px 画布，岗位数字员工的完整岗位列表使用 880px 画布保留原有排布。1100px 以下切换上下布局；720px 以下沿用配图的移动布局、统一宽度并让高度随内容展开，以保留图内文字可读性。只调整首屏，不改变正文配图。
