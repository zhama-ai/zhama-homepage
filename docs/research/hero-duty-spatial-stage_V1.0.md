# 第三屏：开放式值守舞台与前后层次

日期：2026-11-15（Asia/Shanghai）。本记录只对应第三个首页 Banner，不改变第一、第二屏。

## 复用依据与本次判断

复用已完成实际阅读的两份首方设计依据，见 `anywhere-spatial-depth_V1.0.md`、`hero-workspace-material_V1.0.md`：

- [Fluent 2：Elevation](https://fluent2.microsoft.design/elevation)：采用方向一致的清晰关键投影和柔和环境投影，以界面平面的位移与阴影区分距离。仅借用层次原则，不机械复制组件投影数值，不增加厚侧面、底座或体积造型。
- [Linear：How we redesigned the Linear UI](https://linear.app/now/how-we-redesigned-the-linear-ui)：采用减少边框和装饰噪声、用底色与明暗建立焦点的方式；保留既有工作内容与流程，不照搬竞品界面。

此前第三屏与前两屏都以完整大窗口为主体，差异主要停留在窗口内部内容。本次将第三屏改为开放值守舞台，保留已有全部内容，以身份、时间、执行任务和交付结果的空间关系表达持续工作。

## 实现取舍

- 大容器取消完整边框、厚背景与整窗投影，舞台直接透出首页背景；下方保留轻微环境色，未增加文字或图标。
- 数字员工头像与当前时刻作为开放中景，全天时间线位于其后；保留原文、字号和位置关系。
- 左侧只有当前任务采用悬浮表面和投影，其余任务仍为时间列表，避免生成四个并列卡片。
- 右侧现有成果内容成为前景面，使用石墨蓝与轻紫灰。原交付回执伸出成果下缘约18px，通过稍右、稍下的位移与同方向投影拉开距离。
- 当前时刻、当前任务时间与一根图表柱使用克制琥珀色；执行和交付保留青色。没有纯白大面、霓虹外框或新增说明字。
- 桌面同一舞台向左轻透视7度。手机取消透视和大位移，交付回执回到正常排版，收敛投影；不改变原460px桌面、540px平板与420px手机共享舞台高度。

## 保持的运行行为

修改限于 `src/styles/hero-outcomes.css` 的第三屏专属选择器。组件、`outcomes-data.ts`、`duty-playback.ts`、`hero-outcomes.ts` 未修改，四个场景与20.8秒完整时序不变。

静态空间变换放在结果容器上，保留原结果节点的到达动画，因此不会替代其播放变换。未增加动画、全局计时器、滤镜模糊、图片资源或执行状态。离屏暂停、恢复、切换、减少动态效果继续使用原有逻辑。

共享轮播的纵向裁切由主任务负责调整，本文件不触碰 `hero-carousel.css`。右侧表面与回执的外伸控制在原容器的横向内边距内。
