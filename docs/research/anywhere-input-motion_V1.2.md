# 任务入口与执行进度动效细调

访问日期：2026-11-15。沿用 V1.0 的 CapCut 关键帧、Apple Motion 和 SVG 生命周期研究，以及 V1.1 的 SVG 阴影研究。

任务入口保留增强后的入场、波形、发送反馈和图标投影。按用户截图恢复输入框与右侧连接箭头之间的留白：输入框收为 400 源单位宽，发送图标向内移动，汇聚线随卡片中心对齐；设备与平台图标的位置和文案保持一致。

中间执行进度的完成节点由半径 8 调为 10.5，进度线加粗，并增加单个光点沿实际进度线匀速前进。光点在周期第 2.8 至 6.4 秒推进，四个完成节点在 2.9、4.1、5.3、6.5 秒依次确认，仍与输入及成果交付共用 10 秒周期。外环限制在半径 15，不增加模糊滤镜，避免遮挡节点下方的文字。

本次只调整入口与中间进度动画的视觉参数，未修改站内动画管理及产品内容。
