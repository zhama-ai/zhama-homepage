# 首页工作台材质与明暗调整

日期：2026-11-15

## 判断与采用方式

用户比较首页工作台与已认可的八大业务域插图。本次保留工作台的构图、尺寸、文案、透视和动效，集中调整色彩、表面和阴影。原工作台的大面积蓝色与相近亮度使选中角色、容器和内容缺少区分；采用偏黑的深海军蓝底、少量银蓝活动表面、克制的数据色与朝右下方的柔和阴影。

八大业务域插图不变。没有新增卡片、解释文字、装饰线、模糊滤镜或动画。方案文书、经营分析、知识管理三个角色共用表面变量；真实纸张的白色保留。

## 实现与验证

- 修改 `src/styles/hero-luminance.css` 与 `src/styles/hero-spectrum.css`，复用既有样式入口。
- 选中角色标题颜色为 `#102b42`，小字为 `#28465d`。相对选中渐变最暗端 `#93b6d0` 的计算对比度分别约 6.81:1、4.63:1。
- `npm run build` 通过，生成 96 个 Astro 页面、240 组响应式图片及 55 个繁体静态页面。
- `npm run verify` 通过：17,851 项检查、142 个常规页面、27 个重定向、13,421 个本地引用、251 个片段引用，失败项为空。
- `git diff --check` 通过。
- 浏览器检查中文与英文桌面 1280px、手机 390px：没有文档横向溢出；三个数字员工角色可切换，暂停/继续动效可正常控制图表。
- 工作台修改前后文本相同；对比八处边界框，宽高保持一致，仅存在约 0.00006px 的浮点误差。
- 未进行真人可用性测试，不据此声明用户已认可或体验提升。
