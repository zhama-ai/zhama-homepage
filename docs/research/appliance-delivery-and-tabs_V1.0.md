# 一体机交付布局与场景切换调整

日期：2026-11-15。

## 保留基线

保留 TeGo Station 首屏、共用高亮按钮、四组交付正文、四个场景的标题/正文/背景与硬件配置。仅重组交付关系，调整场景导航和切换方式；不添加新产品能力、性能或售后服务范围。

## 已实际阅读的公开依据

- [Radix Tabs](https://www.radix-ui.com/primitives/docs/components/tabs)，本轮已打开并阅读组成、状态和键盘交互，操作了公开示例的 Password Tab。采用整体导航轨道与明确选中态；本项目为 Astro，不引入 React/Radix 依赖，不套用示例表单布局。
- [MDN Element.animate](https://developer.mozilla.org/en-US/docs/Web/API/Element/animate)，本轮已打开阅读关键帧、选项及返回 Animation 对象。采用原生 Web Animations API 控制淡入淡出、取消前次切换；不增加动效库。
- [WAI-ARIA Tabs Pattern](https://www.w3.org/WAI/ARIA/apg/patterns/tabs/)，复用本会话已阅读的键盘与角色规范。保留方向键、Home/End、单一 Tab 停留点、语义关联、锚点直达和无脚本全文展示。
- [NVIDIA DGX Spark](https://www.nvidia.com/en-us/products/workstations/dgx-spark/)，复用本会话已阅读的 Overview、Features、Workloads 与软件栈。借鉴硬件、模型、软件完整交付的分层组织，不采用其性能数字或将其规格引入本产品。

这些公开观察用于设计判断，不证明本产品能力或用户接受程度。

## 采用方案与边界

交付区由四列平铺改为左侧三层整合、右侧移交与售后的组合。左侧保持平行、逐层错位，以不同蓝青线稿、轻阴影和汇聚连线形成关系。重绘算力设备、模型包、平台界面和完成交付四组 SVG 图标。右侧包装与勾选图形只表达交付主题，不代表额外验收、审批或承诺。窄屏纵向组织，保留全部正文。

场景区删除 Tab 前置图标，用共用按钮相近的蓝色填充建立选中态。切换时仅保留一组可访问的内容，上一画面的临时视觉副本去除所有 ID 和语义关联，设置 aria-hidden/inert，淡出后删除。新文案轻移淡入；快速切换取消前次动画；减少动态效果设置下立即切换。无自动轮播。

## 验证方式

使用构建产物的 file URL 离线渲染，阻断网络请求。未重新访问受权限策略限制的 localhost 页面，不宣称完成该端口的浏览器验证或真人可用性测试。

检查简体中文、英文、繁体中文，在 320、390、600、768、1024、1440 像素宽度下交付正文及场景区无横向溢出、文字完整；四组交付内容保留。检查快速连续切换、临时副本清除、唯一选中面板、减少动态效果、键盘导航和无脚本降级。桌面、手机及英文平板图已逐一目视检查。
