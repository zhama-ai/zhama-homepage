# 首页左右对齐

访问日期：2026-11-15。

## 依据与判断

- [MDN：Responsive design](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/CSS_layout/Responsive_Design)：实际阅读弹性网格、响应式媒体及断点章节。采用共享弹性容器、容器内媒体宽度 100%、保留现有响应式断点的做法；不按设备逐个设置互不相干的宽度。
- 源码及 1280px 浏览器检查：首页导航和 Banner 左右边距 36px，普通 section 为 80px，任务协同图与业务领域为 24px。业务领域三列列表还比外容器右边多出约 12px。
- 采用已确认导航和 Banner 的 1240px 最大宽度与既有 `--gutter` 为首页共同网格。仅作用 `.is-home`，不调整内页布局；轮播控制点继续自适应自身宽度。

## 实施边界

- 任务协同图在所属容器内铺满，不再通过视口宽度和负向位移越过内容边界。内部比例、连接线、投影与动画均保留。
- 业务领域使用共同容器，保留八领域图片、右侧文字及桌面三列覆盖布局。三列右边界对齐容器，手机图片继续容器内横向滚动。
- 根据用户后续截图，桌面业务领域插图保持大小并左移自身宽度的 8%，拉开图形与第一列文字的距离；只调整内部插图，不移动共享容器。平板和手机保持原有堆叠位置。
- 同步首页页脚，以免最后一个 section 再次收窄；内页页脚维持原宽。
- 背景保持全幅。统一内容边界不要求每个背景、居中文案或插图内部形状拥有相同可见轮廓。

## 验证范围

实际浏览器检查：1280px 时导航、Banner、任务协同、业务领域、行业方案、CTA 与页脚的共同边界为 36–1244px；1440px 时为 100–1340px；1100px 时为 36–1064px；768px 时为 25–743px；390px 时为 21–369px。各尺寸的页面 scrollWidth 均等于视口宽度。桌面三列列表右端贴齐共同容器，插图左移后左端业务元素完整。

中英繁体首页已检查共享容器。`npm run check`：136 文件、0 错误/警告/提示；`npm run build` 成功，含媒体优化与 55 页繁体静态准备；`npm run verify`：19,766 项检查，无失败。构建保留既有大于 500kB 分块的体积提示。此为源码及浏览器验证，不宣称真人可用性测试。
