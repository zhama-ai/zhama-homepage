# 一体机适用场景版式依据

访问日期：2026-11-15。

用户要求：一体机页面“适用场景”不用卡片，保留现有深色主题；四项业务标题与正文完整保留。

## 阅读来源

- NVIDIA DGX Spark：https://www.nvidia.com/en-us/products/workstations/dgx-spark/ 。实际打开并阅读 Overview、Features、Workloads 与多机扩展内容，查看 Workloads 实际排版。该页按工作负载划分场景，标题先于能力说明；其图片卡片及大段技术描述不适用于本次“不用卡片”的要求。只借鉴一项场景对应一个清晰标题的层级，不引入 NVIDIA 页面的模型规模、集群上限或性能声明。
- shadcn/ui Item：https://ui.shadcn.com/docs/components/base/item 。实际阅读 Composition、Variant、Group 及 ItemSeparator：默认变体透明无边框，媒体、标题、正文可独立组合；组内分隔线用于区分相关项目。采用这一信息组织方式，以原生 HTML 列表和 CSS Grid 实现，不新增依赖，不引入操作按钮。

## 本次实现判断

- 左侧放栏目标题，右侧纵向展开四项场景；每行依次为线性图标、场景标题、完整正文。
- 移除场景卡片背景、四周边框、圆角与独立容器内边距，仅保留行间分隔线；栏目标题上方不增加装饰横线。
- 维持原站色彩、字体与字号比例；手机端正文转到标题下方，四项直接展示，不折叠、不轮播。
- 仅变更本区块的模板和样式，中英文共用结构，交付内容、硬件配置与其他页面不调整。
