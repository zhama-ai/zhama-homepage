# 政务、央国企与互联网方案重构

## 本轮范围

用户否定三个行业共用“摄影 Hero + 三个交替图文段落”的表达。保留银行、保险、证券与一体机，本轮拆开政务、央国企、互联网的页面构成；不恢复此前移除的互联网导航。

## 三种业务叙事与画面

| 行业 | 组织方式 | 产品成果 | 摄影环境 |

| 政务 | 办事卷宗、事项旅程、诉求办理记录 | 跨部门材料包、政策条件对照、诉求责任记录 | 公共服务大厅、多窗口办理 |
