# 多端交办图的空间层次

日期：2026-11-15。

## 范围与判断

用户要求为首页“随时随地，把任务交给数字员工”配图增加空间感，使用透明、阴影和界面层次，避免通过厚侧面、硬件底座或挤出形状实现立体感。保持现有内容、52处原生矢量文字、头像、渠道标识及执行流程。

采用半透明冷灰蓝表面、方向一致的关键投影与环境投影、淡淡的底部环境光。中央平台正面、层级靠前；左右两组分别向内轻转5度，透视距离900px。图像、对应文字和内部流程同组变换。手机保留原有三段正面裁切，取消透视。

## 实读来源

- https://fluent2.microsoft.design/elevation ，访问日期2026-11-15。
- 阅读了 Depth, shadow, and light、Shadow direction、Shadow size、Shadow system 和 Shadows on color surfaces 正文。
- 采用原因：一致的光源方向和“较清晰的关键投影＋较宽的柔和环境投影”可以表达表面距离，并通过主次层级建立焦点。
- 适用边界：仅用于这张宣传插图的视觉层次；不把交互系统组件的投影数值机械搬到图内，也不据此宣称产品能力或真人体验结果。

## 实现

- 在已有可编辑素材上进行确定性处理，保留原内容，不重新生成或改写业务文字。
- 新底图：`public/images/anywhere/anywhere-workspace-depth_V1.18.webp`，1948×760 RGBA，101,934字节；原V1.17为165,988字节。
- 处理脚本：`output/imagegen/refine-anywhere-depth_V1.18.py`；绘图源：`output/imagegen/anywhere-workspace-depth_V1.18.png`。既有版本保留。
- 头像亮部和区域受到保护；矢量文字没有降低透明度或增加模糊。最终WebP压缩有轻微像素色差，未改人物内容。
- 投影与表面反射预先合成进静态底图，不增加运行时模糊或新的动画。
- 三个裁切组共用一张底图。SVG拆为入口、平台、传递三部分，每种流程只保留一份，中央四个执行节点不重复运行。沿用原有10秒时序和离屏、窗口大小变化、减少动态效果控制。
