# 八领域三列布局

2026-11-15，实际阅读 https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/repeat 。采用固定次数的CSS Grid轨道，延续现有repeat与minmax实现；不对窄屏强制三列。

桌面1200px及以上将领域列表排为三列，宽度为原列表的150%加12px，并向左延展相应距离。这样保留原有标题、正文、图片、右锚点和每列阅读宽度，八项自然形成3／3／2。窄屏继续原有两列。

实际浏览器检查：1280px中文每列约197.44px；英文每列约198.77px，八项完整且条目无水平溢出。390px与1024px英文维持两列，页面宽度分别为390px和1024px。Astro及图片与繁体发布构建通过；未新增低价值的样式断言测试。
