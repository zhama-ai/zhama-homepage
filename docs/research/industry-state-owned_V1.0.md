## 官方公开来源与核对结果

### S1：中央企业采购管理

- 文件：《关于规范中央企业采购管理工作的指导意见》，国资发改革规〔2024〕53号。
- 文件日期：2024-07-18；南昌市官方转载页面日期：2024-08-07。
- 正文核对入口：南昌市人民政府官方转载。
- URL：https://www.nc.gov.cn/ncszf/gzwgg/202408/d2d4dc09eaba4806a5a6eaf514251cb1.shtml
- 国资委原站地址：https://wap.sasac.gov.cn/n2588035/n2588320/n2588335/c31372608/content.html ，本次直接打开超时，以前述政府完整转载正文核对。
- 核对到的业务机制：规范采购管理与不同采购方式，依法明确技术和商务要求，应用规范范本与流程，加强内控、审计及采购监督。
- 对页面的影响：采购审查以要求、范本、证明资料对应为主；输出差异、缺项和待核实清单，不替代评审定标，不承诺文件自动合规。

### S2：项目进度、成本与集团经营协同

- 文章：《改革进行时丨中建五局：推动数字化转型 赋能产业链协同》。
- 正文所列日期：2024-03-29；URL 路径含 202412，本记录使用正文日期。
- 正文核对入口：中建五局官方网站。
- URL：https://5bur.cscec.com/5bur/oa/dtxw/202412/3847718.html
- 核对到的业务机制：以项目进度与里程碑承接任务、交付协调及预警记录；合同、结算支付与财务凭证支撑成本归集；目标与实际成本对照；经营指标和数据资源的协同应用。
- 对页面的影响：经营分析必须定位到单位和项目；成本差异要关联预算、合同、变更等资料；履约跟进须接续节点和协调事项。
- 未迁移的内容：文章涉及的现场设备、传感器、专用平台、自动检测能力及其效率指标不作为 TeGo 能力或客户案例。

### S3：隐患整改责任与复核

- 文件：《安全生产治本攻坚三年行动主要任务》。
- 文件日期：2024-01-21；网站发布日期：2024-02-22。
- 正文核对入口：中华人民共和国应急管理部。
- URL：https://www.mem.gov.cn/gk/zfxxgkpt/fdzdgknr/202402/t20240222_478449.shtml
- 核对到的业务机制：隐患排查与整改责任、记录台账或数据库、动态进展和反馈，专业核查与正式销号要求。
- 对页面的影响：数字员工整理检查记录、责任时限、反馈证据与待复核项；正式风险判定、现场验收与隐患销号属于有权专业岗位。
- 未迁移的内容：不声称数字员工通过硬件巡检发现现场隐患，不将资料齐备表述为整改自动完成。

## 采用与排除

- 六岗位为集团经营、招采审查、投标响应、履约跟进、成本分析、隐患整改，与首页已确认的六场景一一对应。
- 正文形成“口径—差异—单位与项目”“要求—证据—审查或响应”“节点与成本—反馈—责任复核”三条业务链。页面痛点沿用首页归纳，不冒称行业量化调研结论。
- 外部官方资料用于校验业务流程、对象、文档及职责，不能证明本产品的部署事实、商业成果、客户背书或性能指标。
- 未编造央企名称、项目、合同、客户、投资金额、提效数字、招采中标结果、资质认证或完成验收。
- 图中 MCP / RESTful API / 数据库为按项目配置的接入方式，授权接入是流程关系；不声称有现成品牌连接器或跨系统权限自动继承。
- 来源记录只保存在本底稿。页面不增加脚注、免责声明、保守兜底小字和与业务无关的解释性卡片。
