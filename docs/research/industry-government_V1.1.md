# 政务解决方案业务重构底稿 V1.1

核对日期：2026-11-15（Asia/Shanghai）

## 业务主线

本版将首页与内页统一为“惠企政策找准对象，办事诉求接到责任”。不再以知识库、系统连接、项目会话三类平台能力拆节，而以政务办理中的判断、材料关系和责任接续组织内容。

| 三项价值 | 业务机制 | TeGo 承接 | 人员确认节点 |
| --- | --- | --- | --- |
| 惠企条件对应企业事实 | 主体资格、支持事项、申报条件逐项对应登记、经营和项目事实；区分事实已对应、缺失证明与待核实项 | 条件拆解、证据匹配、原文定位、申报准备清单 | 服务人员确认政策适用和待核实事实 |
| 一件事材料减少反复 | 对齐牵头和协同部门指南；识别同一主体信息与可复用附件；检查字段、版本和事项差异；集中列出补正 | 跨部门材料预审、共用信息核对、申报材料包、集中补正项 | 受理和审批岗位沿现有流程审核 |
| 12345办理接到责任 | 提取诉求事实、地点、事项；对照职责目录提出分派建议；分派确认后接续反馈、卡点和答复依据 | 诉求研判、职责对应、办理跟进、责任督办 | 职责分派、责任争议、正式答复由有权人员确认 |

首页 pain、value、三 benefits 与内页 features 同序同步。六岗位为政策匹配、办事导引、申报预审、诉求研判、督查督办和综合文稿；岗位过程与成果围绕上述机制重新编写，中英文同步。

## 官方来源与可迁移机制

### 政策条件、材料复用与一件事

《国务院关于进一步优化政务服务提升行政效能推动“高效办成一件事”的指导意见》，国发〔2024〕3号，2024-01-16。

全文核对入口为生态环境部官方转载，原文来源中国政府网：
https://www.mee.gov.cn/zcwj/gwywj/202401/t20240116_1063866.shtml

中国政府网原入口在本轮此前访问返回 403：
https://www.gov.cn/zhengce/content/202401/content_6926255.htm

可迁移机制包括政策条件与服务对象匹配，关联事项和跨部门办理要求衔接，同一信息与材料按授权复用，申请预审与材料补正，明确牵头及配合职责。文件涉及的证照共享、平台互联与免提交是政务系统和授权条件下的业务机制，页面没有将其改写为 TeGo 已建成的跨部门证照网络。TeGo 表述为核对现有授权材料及复用关系，形成材料包与补正事项。

### 12345职责、分派与办理反馈

《国务院办公厅关于进一步规范和提升12345热线服务的意见》，国办函〔2025〕66号，文件日期2025-06-23，转载页面日期2025-06-26。

全文核对入口为福建省人民政府官方转载：
https://www.fj.gov.cn/zwgk/ztzl/zfwzjsygl/ygwj/202506/t20250626_6935468.htm

可迁移机制包括依据法定职责和责任目录分派，职责不清事项协调确认，办理反馈、跟踪、督办和复核衔接，以及诉求数据授权与个人信息保护。页面把 AI 输出限定为职责对应和分派建议，确认后才接续责任办理；不将建议写成行政职责认定或正式对外答复。

## 独立视觉设计

文件：`src/features/solutions/government/SolutionVisual.astro`。

- index = -1：企业政策申报、群众诉求办理双通道。企业通道由惠企政策经 TeGo 条件匹配接申报准备，群众通道由12345诉求经 TeGo 职责研判接办理反馈；两通道各有确认岗位。
- index = 0：惠企政策适用矩阵，以政策条件、企业事实、核对重点逐行对应，单列待核实项及其申报准备接续。
- index = 1：牵头与协同部门要求汇入一件事材料包，共用信息与事项附件区分；缺失附件、字段冲突、版本差异接集中补正和受理审核。
- index = 2：热线受理、职责分派、责任部门、督办协调四条泳道，呈现事实、职责、反馈和复核的接续关系。

四图为二维业务图，使用青蓝克制强调；不复用通用工作台、三系统框或银行式材料卡。真实 DOM 业务标签，中英分别排版，容器查询在窄幅下调整网格和流程布局，未使用整体缩放。未添加虚构人物、数量、效率、状态结果、骨架条、页面顶部装饰横线或来源脚注。

## 产品能力核对

TeGo 的知识检索、原文定位、可复用技能、授权接口与数据库、定时任务、专业子任务、项目版本、组织权限和内网本地模型能力，沿用本仓库产品页和定价功能清单。它们在本版服务于具体政策、材料和责任机制，不再分别占据三个业务章节。

保留旧 workbench 与 visual 字段仅供根代理在统一集成时迁移；本版可见图不读取这些通用工作台元数据。权限和办理责任写入业务主体及必要流程节点，不增加额外免责声明。
