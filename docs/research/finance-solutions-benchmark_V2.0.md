# 国内金融行业解决方案官网调研与改写底稿 V2.0

研究日期：2026-11-20。范围：银行、保险、证券、信托。用途：官网首页行业模块与四类详情页的价值文案和业务配图。此文档为内部底稿，不进入网页正文、图注或页底。

## 研究结论

成熟方案抓住的是一项业务责任背后的真实困难，再用具体业务对象说明变化。有效宣传不止写“文档多、效率低”，而是解释：资料很多仍看不清偿债基础；回复改了多轮仍无法回答实质问询；保单服务了多年却找不到当前适用依据；协议已经变更但核算仍沿用旧口径。

本次采用的共同叙事是“业务困难造成的后果 → 专业支撑怎样改变工作 → 机构获得的专业质量”。数字员工承接准备、比对与接续，价值落到专业人员看得更深、依据更完整、责任更连续。功能名和操作过程置于后层，不能在开篇列知识库、工具调用、配置与工作流。

不选一个厂商全盘复制。百度的保险页在行业痛点上具体；金证的智能投行页把风险前置与披露证据相连；通联强调机构能力、研究积累和投资风险；用友金融、南天、宇信的信托内容提供项目、核算、报送和跨渠道服务的行业对象。这些优点分别采用，旧式系统架构堆叠和长产品清单不沿用。

## 四行业痛点与价值锚点

### 银行

- 授信：数字能够勾稽，不等于企业解释得通。财报、送审说法和本行规则之间的差异，应指向收入质量、资金占用、偿债能力与第一还款来源。
- 贷后：信息有更新，不等于风险认识有延续。需要把当前变化与历次核查关联，让人员知道本次究竟应该核实什么。
- 合规：法规能够检索，不等于现行要求进入本行制度。价值在于影响范围、内规责任和条线执行依据清楚。
- 机构：专家意见有价值，但只停在少数人身上不能扩展。经确认的本行方法进入具体岗位作业，支持总分支机构在同类问题上沿用同一依据。

### 保险

- 核保：反复补件仍未澄清健康告知与病史矛盾，才是专业痛点；不把“材料多”单独当成价值。
- 核赔：医疗事实、费用和本单责任必须对应。图中应保留真实责任问题，不做“全绿通过”或自动赔付承诺。
- 长期服务：投保时条款、有效批单和停售产品材料决定本单依据，不能用当前在售产品知识替代历史契约。
- 疑难：医学核保、财务核保与高额事项专家应看到同一个案、已查依据与未决问题，而不是轮流重新收集前情。

### 证券

严格遵循用户提供的投行与交易 V6 大纲，四主题为申报质控、问询证据、交易确认、执行结算；投研与财富管理只用于竞品叙事研究，不扩张本轮页面范围。

- 申报：版本改了但引用仍旧，意见存在但终稿未落实，实际后果是披露依据与核查充分性受影响。
- 问询：文字写得完整仍未回答实质问题，必须看合同、资金记录与核查结论是否支撑解释。
- 确认：主协议、补充协议和确认书之间的差异影响生效、支付与到期权责，不能只画对账表。
- 结算：执行约束、委托成交与结算记录的时点及口径应对应，专业人员聚焦真正异常。

### 信托

严格遵循用户 V6 大纲，四主题为契约参数、存续档案、多源尽调、跨渠道服务。

- 契约：补充协议已改变约定，而核算沿用旧参数，影响各方权益与责任。
- 档案：从成立、存续到清算，资料归档不完整会使履职复核缺少依据；“文件存在”不等于“履职证据完整”。
- 尽调：同名主体、不同查询时点、不同来源的风险记录不能机械合并，重点在主体身份和证据可核实。
- 服务：监管转办、热线与历史事项本质上可能是同一客户关切，机构要保持责任、时限与前情连续。

## 图文叙事要求

每行业四张主题图，加独立首屏综合图。每张图承担一个实质变化，不能用同一大屏和同一文件卡片换标题。正视、水平文字、真实间距，痛点侧和改善侧有同一业务对象贯穿，用一个单向衔接表达数字员工的专业支撑。浅层遮挡与方向一致投影保留空间，不用斜切和厚 3D。

图面至少出现一项可辨识的真实业务矛盾或后果：告知与病历冲突、旧版引用、失配的合同参数、缺失的关键履职材料等。改善侧展示该矛盾如何转为清楚、有据、能负责的专业工作，而非换成全绿图标或一份漂亮报告。

所有数字员工支撑均以产品已确认的知识、技能、任务、记忆、连接和组织治理能力为基础。人工专业审阅自然写进业务正文，不额外添加页底免责小字；不迁移任何竞品的客户实测、市场份额、准确率或收入数据。
