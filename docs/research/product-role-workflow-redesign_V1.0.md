## 设计判断

岗位数字员工页强调“成熟岗位方法如何进入每次交付”，明确区分静态数字员工模板与独立运行的数字员工。业务呈现依次为招募配置、投标编制交付、周期任务与记忆。图形交由原生二维 UI 呈现岗位、会话、任务记录和真实文字内容，避免空框、加载条、无业务含义的图形。

分布式任务协同页以同一个尽调准备任务贯穿三个界面：先安排资料检索、数据提取、风险梳理，再呈现子任务状态与专业返回，最后汇总报告材料与复核事项。保留原投标文件复核场景，在场景模块完整呈现，避免整个页面只有抽象编排术语。

## 能力保留基线

岗位页保留：岗位职责/技能/工作区文件封装为模板；从模板招募独立数字员工；配置与所需审批；员工使用、知识访问、插件业务委托分别授权；定时任务与运行/投递结果；按使用者隔离的个人档案、长期记忆和工作日记；组织策略下复盘并沉淀技能；投标编制与合规预审的人工复核。

协同页保留：主 Agent 围绕目标与工作规则拆分任务；按配置调用专业子 Agent；独立事项并行；运行/完成/错误状态；结果回到主任务继续整理与审阅；尽调编制和投标复核两个业务场景。没有增加自动重试、无限并发、跨系统继承权限或无人审批承诺。
