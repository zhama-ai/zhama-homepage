## 当前账号能支持什么

- 账号为免费版；分析模块显示账号没有分析权限，没有开通分析云。

## 采用的接入方式

推荐在正式网站域名、满足网站统计授权条件时加载一次官方 HTTPS 异步代码。当前官网是多页网站，每次页面加载计一次规范页面 PV；不对滚动、按钮点击、Tab 切换或弹窗打开额外发送虚拟 PV。

如果需要清理统计页面地址，官方支持在加载 SDK 前依次排队：

```js
window._hmt = window._hmt || [];
window._hmt.push(['_setAutoPageview', false]);
// 来源覆盖值、页面地址由应用自己的固定规则生成。
window._hmt.push(['_setReferrerOverride', sanitizedReferrer]);
window._hmt.push(['_trackPageview', canonicalPathname]);
```

其中 `_setAutoPageview` 和 `_trackPageview` 有公开文档；`_setReferrerOverride` 的行为由当前公开 SDK 源码确认，未找到对应的现行官方 API 文档。接入后应将其纳入 SDK 更新复核，不把这一接口描述为有完整公开文档保障的稳定契约。

推荐规范页面地址仅使用站内 pathname，不带任意查询值或 hash。来源地址可按本网站规范 pathname、外站 origin 的规则缩减；这会降低外站具体来源页面的细分能力。不要改写供应商脚本，也不要用临时修改、恢复浏览器地址的方式假装供应商完全不接触页面信息。

依据：

- [如何获取统计代码](https://tongji.baidu.com/web/help/article?id=175&type=0)：默认推荐异步代码，支持 HTTPS，不支持改造统计代码。
- [_setAutoPageview](https://tongji.baidu.com/holmes/Tongji/统计开放手册/JS-API技术文档/_setAutoPageview)：默认自动 PV 为 true；false 仅关闭自动 PV，不是关闭全部采集。
- [PV 跟踪部署说明](https://tongji.baidu.com/holmes/Analytics/技术接入指南/JS%20API/JS%20API部署说明/PV跟踪)：明确给出关闭自动 PV、手动发送重命名 PV 的组合；要求相关队列位于统计脚本前。
- [_trackPageview](https://tongji.baidu.com/holmes/Analytics/技术接入指南/JS%20API/JS%20API技术文档/_trackPageview)：参数必须是以 `/` 开头的相对路径。

## 真实咨询成功与虚拟 PV

官方 PV 跟踪说明明确：手动虚拟页面与真实页面有相同 PV 效果，会进入最新访客和受访页面报告。因此每一次虚拟成功 PV 都会增加总 PV，不能称其为不影响浏览量的事件统计。

如需在当前基础能力内识别咨询成果，仅在咨询服务明确返回成功后，追加一次固定成功路径 PV；点击咨询按钮、打开表单、校验失败或接口失败都不代表提交成功。相同成功动作需要在客户端去重。使用独立的固定路径前缀，便于区分真实页面和成功动作。

接入还需要单独保存后台页面转化目标。官方[页面转化说明](https://tongji.baidu.com/holmes/Analytics/操作手册/使用设置/转化设置/基本转化设置/页面转化)支持将表单提交成功设为目标，并推荐按访问次数计数，避免刷新造成多次转化。网站域名下基础限制为 50 个页面转化目标。PV 跟踪说明另明确：虚拟页面可作目标页，不能作页面转化的入口或中间页。

## 传统事件与五个自定义变量槽

[_trackEvent 官方文档](https://tongji.baidu.com/holmes/Analytics/技术接入指南/JS%20API/JS%20API技术文档/_trackEvent)支持：

```js
window._hmt.push(['_trackEvent', category, action, label, value]);
```

category、action 必填；空串或 `-` 会使该事件被丢弃。label 可选，value 为 Number。category × action × label 的多样性乘积不得超过 10,000，超过会丢弃；文档所述报告最多展示点击量前 3,000 项。

该 SDK 可以接收传统事件，但当前账号没有事件报告权限。可保留有限的公开交互标签用于将来具备权限后的采集衔接，不能声称当前后台已具备点击、滚动、Tab、下载的完整事件分析，也不能把代码队列通过测试写成报表已验证。

[_setCustomVar 官方文档](https://tongji.baidu.com/holmes/Tongji/统计开放手册/JS-API技术文档/_setCustomVar)规定：

- index 仅 1～5；每个索引对应的 name 首次使用后固定，之后不能更改。
- scope 为 1 时按访客持续生效，为 2 时当前访次生效，为 3 时页面级别，默认 3。
- 报表按 session 统计，同一访次的同一槽最终仅保留一个标签；访客级优先于访次级，访次级优先于页面级。
- 同一访次中，访次级取最后一个访次级标签，页面级取第一个页面级标签。

因此页面级变量不能被表述为“每个页面都能独立交叉分析”的属性。槽位宜少而稳定，可用于首个标记页面的语言、页面类型等有限公开分类；命名与作用范围要在首次上线前固定。官方[自定义变量报告说明](https://tongji.baidu.com/holmes/Tongji/使用指南/数据报告/访客分析/利用自定义变量报告自定义访客属性)描述的是自定义访客群体的访问次数、平均访问页数和跳出率等，报告实际可达性仍取决于账号。

## 不采用的分析云 API

[JS API 使用手册](https://tongji.baidu.com/holmes/Analytics/技术接入指南/JS%20API/JS%20API%20使用手册)对以下功能提出分析云后台配置要求：

- `_trackCustomEvent`：必须先在“分析云-管理-数据管理”通过“JS API 添加事件”创建事件并关联属性。
- `_setPageviewProperty`：必须先为预置 PV 事件关联自定义属性，且在 PV 前调用。
- `_setAutoEventTrackingProperty`：依赖全埋点，并先为元素点击预置事件关联属性。

## 广告归因参数

官方[hm 参数与 utm 参数的对应关系](https://tongji.baidu.com/holmes/Analytics/产品使用指南/使用设置/推广设置/hm参数与utm参数的对应关系)说明，通过落地 URL 识别广告信息，支持以下对应关系：

| UTM | 百度参数 | 官方维度含义 |
| --- | --- | --- |
| utm_source | hmsr | 媒体平台／指定广告来源 |
| utm_medium | hmpl | 推广计划 |
| utm_campaign | hmcu | 推广单元 |
| utm_term | hmkw | 关键词 |
| utm_content | hmci | 创意 |

对应两种参数同时存在时，以 hm 参数为准。hmsr 为必填的物料信息；设置单元前需有计划，设置关键词和创意前需有单元。

此处按百度实际映射解释，不把常见 UTM 习惯自行替换为该产品的字段语义。推广链接只使用事先定义的公开活动名称，不将姓名、手机号、邮箱、公司联系人或咨询内容编码进 campaign 参数。

## 当前公开 SDK 的隐私行为核查

公开脚本：<https://hm.baidu.com/hm.js?e6770cf50973b8dbda39ef528cf8a6ba>。本次仅下载文本阅读，未执行脚本，未向统计收集接口提交访问或事件。没有保存账号密码、登录态或后台凭证到本文件。

2026-11-21 下载到的站点配置中，`etrk`、`cetrk`、`cptrk`、`ctrk` 为空，`aet` 为空串，`spa` 为 0。其 API 实现包含 `_setAutoPageview`、`_trackPageview`、`_trackEvent`、`_setCustomVar`、`_setReferrerOverride`、`_setAutoTracking`；没有 `_trackCustomEvent`、`_setPageviewProperty`、`_setAutoEventTracking`。这与当前基础账号、未开通分析云的状态一致。

源码检查确认：

1. SDK 初始化先读取 `document.location.href`、`document.referrer`、页面标题与设备相关信息，并从原始落地 URL 提取 UTM/hm 参数到独立的广告归因字段。
2. `_trackPageview` 更新统计页面 URL；没有来源覆盖时，还会用上一个统计 URL 或当前原始 location 作为来源。`_setReferrerOverride` 接受字符串，可防止手动 PV 重新把 location 用作来源。
3. `_trackEvent` 自身不重新读取 location，而是沿用现有统计 URL、来源和归因字段，另填入 category/action/label/value。
4. 清洗传给 `_trackPageview` 的 URL 不会反向清除初始化阶段已解析的广告归因字段。因此不能承诺“任意查询参数或个人信息绝不会进入第三方 SDK”；若错误地把个人信息放进 UTM/hm 参数，仍有外传风险。当前 SDK 解析器也接受 `#` 分隔的这些参数，并额外读取 `hmmd`；如应用按推广参数合法性决定是否加载统计，不能只检查 URLSearchParams 所见的 query，也要覆盖 hash 与 `hmmd`。
5. 脚本包含读取元素文本、非密码输入值的通用函数定义，但本次未发现输入值提取函数在当前脚本中的调用。不能仅凭函数定义声称当前正在上传表单内容。
6. 热力图代码可以读取目标链接 href、元素位置及尺寸；当前 `ctrk` 为空，没有启用该采集路径。后台以后启用圈选或热力功能会改变边界，需要重新检查。
7. `_setAutoTracking(false)` 检查的是公共发送开关，同时抑制手动 PV、手动事件和自动数据发送；不是“仅关闭热力图”的开关。官方[关闭数据采集说明](https://tongji.baidu.com/holmes/Tongji/使用指南/统计设置/其它设置/如何关闭数据采集)的代码排版将 false 放到 push 数组外，当前 SDK 源码实际要求数组第二项：`['_setAutoTracking', false]`。不得照排版错误实现。

最小化边界应写为“本网站自定义埋点不读取、不追加表单内容和联系信息；统计服务仍处理页面浏览、来源、设备、Cookie 与广告归因等信息”，而不是“统计不处理任何个人信息”或“供应商永远不读取任何 URL”。本次不启用自动圈选、热力图、用户 ID、表单字段自动采集或分析云自定义属性。

## 告知与授权依据

百度[隐私政策](https://tongji.baidu.com/web/help/article?id=330&type=0)于 2026-06-15 更新并生效，要求开发者告知集成情况、个人信息处理规则并取得合法有效的授权；未获得授权时，提供停止采集的控制工具。其适用说明包含 PC 网站、移动网站等终端，不仅是移动 App。

[百度统计服务条款](https://tongji.baidu.com/holmes/Analytics/隐私合规指南/百度统计服务条款)与[开发者数据合规与安全承诺书](https://tongji.baidu.com/holmes/Analytics/隐私合规指南/开发者数据合规与安全承诺书)要求合法、正当、必要，明示目的、方式、范围并取得同意，不收集与业务或统计无关的个人信息。

网站告知应与实际加载条件、字段与授权机制一致。不能因为事件标签是固定文案，就声称 SDK 不使用 Cookie、不处理浏览器与设备信息，或以“不写表单字段”替代统计服务所需的告知与授权。

## 本次落地的授权与数据范围

以下为 2026-11-21 对新接入源码的核查结果，属于实现检查，没有向生产收集接口发送访问：

- `AnalyticsConsent.astro` 与 `consent.mjs` 提供中英文允许／拒绝入口、隐私政策链接和页脚统计偏好入口；未作选择时不加载百度统计 SDK。
- 选择保存为 `localStorage('tego-analytics-consent')`。只有值为 `granted`、正式 HTTPS 域名符合要求、没有 DNT／GPC 隐私阻止信号且广告参数通过校验时，才进入 SDK 加载。
- 来源按站内规范页面／站外 origin 缩减，手动 PV 使用规范 pathname。未知页面映射为本地化 404 分类，不将任意未知路径加入事件标签。
- 自定义事件仅使用固定分类、动作、目标枚举。资源搜索仅记录是否使用，不读搜索词；咨询状态仅接收固定 status／reason，不读取表单字段、联系人、咨询正文、请求 ID 或服务器响应内容。
- 真实咨询成功状态必须承接本次提交状态，随后才发送一次固定成功目标 PV。重复成功通知不重复计数；后台目标已按访问次数配置。
- 拒绝和撤回调用 `_setAutoTracking(false)`，清除尚未交给 SDK 的队列，移除本模块监听器与计时器；跨标签页撤回通过 storage 事件执行相同停止操作。撤回不刷新页面，保留正在填写的咨询草稿。
- 当前文档中统计已停止后，再次允许只保存 `granted` 并提示下次访问生效，不重启当前 SDK 或重复发送页面 PV。进入下一新文档时，按已保存的授权选择正常初始化。
- 当前事件分类为一个固定 category、27 个固定 action、最多 276 个 label，总多样性乘积为 7,452，低于官方 10,000 上限。页面与行业信息可由统计页面路径承载，不再重复拼入所有事件标签。

本地自动化检查覆盖了来源与路径清洗、业务值不进入队列、hash／嵌套广告参数、真实提交成功去重、待加载 SDK 队列撤回和多样性上限；9 项授权测试同时覆盖不刷新页面、咨询草稿保持和跨标签页撤回。其范围是本网站包装层，不代表第三方 SDK 的服务端行为已通过本地测试，也不代表生产报表已收到相应数据。
