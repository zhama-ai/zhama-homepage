# 七行业解决方案重构记录 V3.0

研究与实施日期：2026-11-20。本轮范围为银行、保险、证券、政务、央国企、信托、企业通用，覆盖首页行业入口、方案总览与中英文详情。

## 参考依据

本轮分组阅读国内企业的行业方案、场景方案和客户实践，并对主要参考页面进行了浏览器视觉检查。完整来源、页面观察及读取限制分别保存在以下底稿：

- [金融方案官网研究](finance-solutions-benchmark_V2.0.md)
- [政务、央国企及通用企业研究](enterprise-solutions-benchmark_V2.0.md)
- [官网图文设计基准](solution-web-design-benchmark_V2.0.md)
- [客户案例阅读记录](solution-case-reading_V1.0.md)

重点采用神策银行的专题分层、观远客户案例的具体经营问题、飞书百应案例的组织改变，以及金证投行、百度保险等方案中的专业业务对象。参考的是叙事和组织方法，厂商客户、指标和落地成绩不迁移到 TeGo。

## 内容重构

每个行业围绕四项独立业务价值展开。行业痛点须包含实际业务后果，不能用“材料多、效率低”作为全部论据。数字员工的作用落实到具体事实、适用依据和专业人员的判断，避免将岗位配置、资料上传、调用工具写成方案主线。

| 行业 | 四项业务主题 |
| --- | --- |
| 银行 | 财报矛盾与偿债实质；贷后风险延续；外规影响与现行执行依据；本行专业方法覆盖分支机构 |
| 保险 | 告知与病史矛盾；医疗事实与本单责任；长期保单适用版本；疑难个案专家接续 |
| 证券 | 申报版本与引用质量；实质问询证据；有效协议与交易确认；执行结算差异 |
| 政务 | 同一情形的材料要求；采购竞争条件审查；专项责任与实际障碍；政策变化进入服务口径 |
| 央国企 | 合同重大责任；整改实证与缺口；经营变化判断；集团共性问题与单位差异 |
| 信托 | 有效契约与核算参数；存续履职证据；主体及时点相符的尽调依据；跨渠道客户事项接续 |
| 企业通用 | 合作约定责任；员工事项准备；客户条件进入方案承诺；经营讨论越过对数 |

每个专题正文约两到三句，配合三个简短业务结果，保持客户收益与产品支撑之间的对应。中英文同时校订，首页及总览复用同一内容源。

## 视觉实施

详情页改为四个完整图文专题，采用并排、宽幅、反向并排等节奏。每个主题拥有独立业务图，中英文共 56 张；图片内含具体矛盾、对应依据与改变后的专业关注点，不以一张总览图承担整页信息。

图片由配置的图像服务生成，再逐张审查。弃用只有名词框和箭头的早期稿；最终版本检查并修正了错字、主体层级错误、模型补写的公司名称、日期、支付期限及跨行业内容。图片使用正视二维构图、薄面、透明度与柔和阴影，避免卡通人物、机器人、硬件摆设和等待加载式横条。

发布图仅去除无内容的上下留白，并将深色外围平滑处理为透明，保留完整业务文字和主体。实际尺寸写入内容数据，避免固定画幅撑出多余高度。最终资产、原始图路径、裁切范围与校验值登记在 [配图清单](industry-value-artwork_V3.1.json)。

移动端依次展示标题、图片和正文，图片支持放大、原始尺寸查看及关闭后焦点恢复。首页保持六个既有行业 Tab，企业通用保留在方案总览；一体机页面和首页八大业务领域图不在本轮变更范围。

## 验收范围

验收包含四专题与资源完整性、共享按钮规范、图像格式与尺寸、中英文一致性、繁体静态生成、桌面布局、手机溢出和图片预览交互。执行 `npm run check`、`npm test`、`npm run build` 和 `npm run verify`，最终结果记录于本轮交付回复。
