# 导航菜单视觉整理

访问日期：2026-11-15。

## 公开依据

- https://vercel.com/ ：读取官网 HTML。顶栏使用 14px 文本与中性色，展开状态提升亮度，内容组织在同一面板中。采用紧凑顶栏、普通与高亮状态的对比；不采用其较大的展开条目字号和外链箭头。
- https://linear.app/ ：读取官网 HTML。普通导航链接与展开触发器采用一致结构，桌面与移动入口分别处理。采用一致字阶和整面板组织；不移植品牌内容，也不把源站阅读当作真人可用性验证。
- https://www.w3.org/WAI/ARIA/apg/patterns/disclosure/examples/disclosure-navigation/ ：读取官方实例。保留 disclosure 按钮、aria-expanded、aria-controls、普通链接列表、Tab 遍历和 Escape 返回触发器；视觉改版不引入 ARIA menu。

## 本项目判断

实际浏览器读取到顶栏 16px、菜单标题 15px、小字 12px。typography.css 在 navigation.css 后重复设置导航字号，导致导航无法独立控制。

导航字阶集中到 navigation.css：桌面顶栏 14px，展开条目 13px，现有说明 11px；手机顶层 15px。正文和已认可配图不调整。说明采用中性灰蓝，保持自然换行与原有全文。

产品和方案面板继续使用双列，收窄宽度、统一密度与深色表面；资源和语言菜单沿用相同材质与字阶。保持原有入口、顺序、文案、切换语言和展开逻辑。

图标使用相同语义轮廓的两套 SVG：常态为中性线稿，高亮为品牌蓝线稿与局部填充。仅在悬停、键盘聚焦或当前页面时切换，图标尺寸和占位保持一致。

Exa 未配置；部分其他来源连接失败，未纳入判断。此记录区分公开源码阅读、设计判断与后续本地运行验证，不声称真人测试通过。

## 本地验证

- 构建成功：96 个 Astro 页面，并生成 55 个繁体静态页面。
- 既有站点验证：19,604 项检查通过，覆盖本地链接、锚点与页面结构；3 个语言测试通过。
- 实际浏览器核对：1280px 中文、1101px 英文、390px 手机英文及繁体页面；菜单未出现横向溢出或文字裁切。手机展开起点与 72px 页头底部一致。
- 实际操作核对：产品、方案、资源、语言菜单互斥展开；Tab 聚焦首个入口后仅该图标高亮；Escape 关闭并返回触发器；当前页图标高亮；点击菜单外部关闭。悬停与键盘聚焦采用同一组 CSS 状态规则。
