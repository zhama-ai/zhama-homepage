# TeGo 官网设计与组件规范

所有页面沿用 TeGo 数字员工协作平台的深色底和蓝色操作色。用版心、字号和留白区分层级，业务图沿用已有背景和语义配色。页面顶端不加装饰线。

## 布局与文字

| 规则 | 大屏 > 1100 px | 中屏 701–1100 px | 窄屏 ≤ 700 px |
| --- | ---: | ---: | ---: |
| 页面边距 | 48 px | 32 px | 20 px |
| 连续区块间距 | 96 px | 72 px | 56 px |
| 网格间距 | 32 px | 24 px | 16 px |
| 首屏顶部间距 | 64 px | 48 px | 32 px |
| 卡片内边距 | 24 px | 24 px | 20 px |
| 页面标题 | 52 px | 44 px | 34 px |
| 区块标题 | 36 px | 32 px | 28 px |
| 小节标题 | 24 px | 24 px | 22 px |
| 导语 | 18 px | 18 px | 16 px |

卡片标题为 20 px，正文 16 px，控件 15 px，日期、版本等辅助信息 14 px。大标题、小标题、正文分别使用 1.2、1.35、1.7 倍行高。页面内容最长 1200 px，连续阅读栏最长 760 px。正文和控件不随屏幕缩小字号，优先换行和改变列数。

`src/styles/design-system.css` 是共享令牌的维护入口。内容区使用 `.container`；连续区块用 `.ui-section`，每个区块承担一半垂直间距。组件内部使用 `.ui-grid`、`.ui-stack` 与 `.ui-surface`。卡片圆角为 8 px。图片、轮播或表格可依据内容设置单独的重排阈值，不另设页面边距或标题字号。

## 配图

| 类型 | 画框 | 显示方式 |
| --- | --- | --- |
| 六页产品首屏 | 10:7 | 使用同一画框与网格；两列刚切换或进入窄屏时，内容较多的图可向下扩展 |
| 产品正文概念图 | 16:10 | 业务组和流程保持顺序，空间不足时纵向重排 |
| 行业照片 | 3:2 | 保留业务主体，可设置焦点位置 |
| 博客列表缩略图 | 16:9 | 统一卡片预留空间；文章内保留原图比例 |

当前产品概念图的主要文字保持为 HTML，标题、内容、辅助标签分别为 16、13、11 px。使用组件内的语义令牌；文字可以换行。源图存在烧录文字时，新增图应把重要业务文字放到可本地化的网页层，或者为各语言提供对应资产。历史文章插图、实际界面截图和首页已确认插画保留原素材，不通过改图重写事实。

业务图片填写有意义的替代文本；纯装饰图使用空替代文本。源素材提供真实宽高，画框预留加载空间。需要完整展示内容的图使用 `contain` 或自然比例；仅对可裁切照片使用 `cover`。

## 组件边界

| 层 | 维护责任 |
| --- | --- |
| `src/layouts/Layout.astro` | 文档外壳、SEO 元数据、导航、页脚和统计授权 |
| `src/components/ui/` | 无业务依赖的页头、文章卡片等可复用结构 |
| `src/components/product/` | 产品首屏、正文叙事、配图和面包屑 |
| `src/features/` | 页面布局、界面状态、业务文案和各语言的数据 |
| `src/pages/` | 路由、内容加载与页面元数据 |

同义组件在所属层维护一份，差异通过属性、数据或插槽传入。某页独有的结构留在功能目录中；布局 CSS 由所属组件或功能入口加载。不要在页面重写 `.container`，也不要复制全局元素规则。保留业务原有入口、锚点、标题层级和操作状态，按实际界面核对翻译。

## 变更检查

1. 构建前运行 `npm run release:check`，核对三语页面结构、站内链接、canonical、hreflang 和统计授权入口。
2. 使用发布产物检查简体、英文、繁体；比较同类页标题、媒体边界与版心。在宽屏、平板和 320/390 px 窄屏检查长英文、图片内容、触屏与键盘操作。
3. 核对功能相关的导航、标签页、筛选、旧地址和表单反馈。百度统计保持正式域名与访客授权条件；正式域名采集和搜索索引在发布后分别查验。

## 设计依据

2026-11-23 阅读 [Carbon 间距规则](https://carbondesignsystem.com/elements/spacing/overview/)、[IBM 字体系统](https://www.ibm.com/design/language/typography/type-scale/)、[GOV.UK 字号与行高](https://design-system.service.gov.uk/styles/typography/)、[web.dev 图片布局预留](https://web.dev/articles/optimize-cls) 和 [Astro 组件与插槽](https://docs.astro.build/en/basics/astro-components/)。采用共用间距、按用途分配字号、预留图框和复用模板的做法。具体数值、配色与语言换行根据 TeGo 的内容和版心确定；不引入外部配色、字号表或业务模式。
