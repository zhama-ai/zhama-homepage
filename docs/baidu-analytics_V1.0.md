# 百度统计接入与维护

核查日期：2026-11-21。官网统计标识为 `e6770cf50973b8dbda39ef528cf8a6ba`，这是公开的站点代码，不是登录凭证。实现使用百度官方异步 SDK，没有添加第三方统计依赖，也没有保存后台登录信息。

## 加载范围

全站共用布局接入授权组件，简体中文、繁体中文和英文使用同一个统计站点。仅在 HTTPS 的 `www.zhama.com` 和 `zhama.com` 上、访客允许统计后加载。正式发布配置将裸域名跳转到 `www.zhama.com`；本地预览、测试域名和 HTTP 不加载百度脚本。

首次访问显示简洁的允许／拒绝选择。选择保存到本域名的 `tego-analytics-consent`，值为 `granted` 或 `denied`。页脚“访问统计设置”可以重新选择；浏览器拒绝存储时保持关闭，不把无法保存的选择当成授权。尊重 GPC 和 Do Not Track 信号。

撤回后停止 SDK 采集、清理尚未发送的队列、移除应用事件监听和计时器，不刷新页面，保留正在填写的咨询。其他标签页撤回或清除该偏好时也会停止。撤回后重新允许的设置在下次页面访问时生效，当前页面不恢复旧 SDK 或重复上报 PV。撤回不会删除百度已经收到的历史数据，也不声称可以从网站删除百度域名下的 Cookie。

## 页面与来源

每个正式页面只发送一次规范路径 PV，关闭 SDK 的默认自动 PV，避免重复。语言和页面类别从公开路由派生，行业详情和产品详情保留各自路径。博客发布后，构建核验会检查所有新路由是否已被统计分类覆盖。

手动页面地址不带查询参数或片段；本站来源仅保留已知页面路径，外站来源缩减为域名。因此外站具体引荐页面、搜索词等细分信息可能减少，浏览器本身也可能不提供这些内容，不能承诺完整恢复。

UTM 和 hm 广告归因由官方 SDK 独立识别。本网站在加载前校验推广参数，只允许受控格式的公开活动名称或编码，拒绝明显的邮箱、手机号、异常长度和片段推广参数。营销链接不能放姓名、联系方式、咨询内容或客户编号。格式检查无法识别全部个人信息，不能替代投放链接审核。

## 已接入的交互

所有传统事件使用 `website` 分类，动作采用固定名称，标签只包含语言和白名单目标，不包含自由文本、完整链接、安装包地址、表单字段、错误原文、用户 ID 或线索 ID。动作与目标的最大组合有自动化测试约束，低于百度文档规定的 10,000 上限。

| 业务动作 | 事件动作 | 口径 |
| --- | --- | --- |
| 产品、行业、页面与语言入口 | `navigation.*` | 点击入口，目标为公开页面分类 |
| 立即体验 | `conversion.try_product` | 前往数字员工平台的点击；不代表注册或激活 |
| 联系入口 | `conversion.contact_click` | 打开联系页面；不代表线索提交成功 |
| 文档入口 | `outbound.documentation` | 前往文档中心的点击 |
| 当前／历史安装包 | `download.current` / `download.history` | 点击安装包；不代表文件下载完成或安装完成 |
| 行业、下载、一体机场景、资源切换 | `content.*` / `resource.filter` | 实际选中项改变，覆盖点击与键盘，不计初始化和自动切换 |
| 资源与搜索 | `resource.open` / `resource.search_used` | 资源分类、是否使用搜索；不读取或上报搜索词 |
| 微信、邮件与电话 | `contact.*` | 入口交互，只区分渠道，不发送联系地址 |
| 咨询表单 | `contact_form.*` | 校验失败、有效提交开始、接口失败和接口确认接收成功 |
| 阅读深度与停留 | `engagement.scroll` / `engagement.visible_time` | 25/50/75/100% 深度及可见页面累计 30/60/120 秒，每档一次，隐藏时间不累计 |

## 已保存的咨询目标

后台路径为“使用设置 → 转化设置 → 基本转化设置 → 页面转化”。本次已保存且核对为启用状态：

- 名称：官网咨询已接收。
- 类型：留言咨询。
- 目标网址：`https://www.zhama.com/virtual/contact-success/`。
- 记录方式：按访问次数。
- 后台目标 ID：`1557269`。

只有联系服务返回成功 HTTP 状态且 JSON 的 `success` 为 `true` 后，客户端才发出一次成功虚拟 PV。校验失败、提交按钮点击、打开成功弹窗或网络失败均不能单独触发该转化。服务端成功表示咨询已接收，不代表邮件或飞书通知已经送达。

成功虚拟 PV 会额外增加一次总 PV。阅读真实页面流量时排除 `/virtual/` 前缀；查看咨询成果时选择上述目标。按访问次数统计意味着同一访次多次成功咨询也不会等同于多条独立线索，业务线索数以联系服务记录为准。

该路径只用于统计命中，不生成成功网页，也不应发给访客作为真实访问地址。没有设置虚构转化收益，没有把停留时长、浏览页数或体验点击配置为成功咨询。

## 当前免费账号的限制

基础访问、来源、页面、地域、新老访客等，按当前可达报告使用。SDK 采集设备环境不等于账号具有完整设备分析报告。后台已确认账号没有分析云权限，事件分析显示无权访问；旧 trackevent 事件转化也不能新增。

传统事件代码已接好，但本次没有验证这些事件在当前账号的高级报表可见，也不能保证日后开通权限能补回历史明细。当前可用的咨询转化采用已配置的页面目标。没有申请试用、购买服务、开启自动圈选或热力图，也没有修改账号权限。

如后续开通分析云，应先在后台定义事件和属性，再按开通站点实际提供的 SDK 对接，重新核查采集和授权；不能仅把 `_trackEvent` 改名为 `_trackCustomEvent`。立即体验后的平台注册、登录和使用行为属于另一个应用，本次官网点击统计不覆盖该应用内部。

本次完成后台目标配置和代码验证；正式网站部署、真实采集到达和生产转化命中需以实际发布结果为准。官方文档、源码核查与账号权限依据见 [接入研究记录](research/baidu-analytics_V1.0.md)。
