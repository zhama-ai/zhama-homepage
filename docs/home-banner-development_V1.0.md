# 首页三屏轮播

2026-11-14。首屏沿用已确定的工作台与背景，其余页面区块保持现有实现。轮播组件为 `src/components/HeroCarousel.astro`，业务文案与数据在 `src/features/home/banner-data.ts`，交互控制在同目录 `hero-carousel.ts`。

采用已阅读的 W3C Carousel Tutorial（https://www.w3.org/WAI/tutorials/carousels/ ，访问日期 2026-11-14）中的手动控制、暂停、键盘访问做法。首屏 14 秒、任务屏 18 秒、成果屏 12 秒；悬停、后台、离屏暂停；手动选择后保留该屏，重新播放后恢复自动切换。减少动态效果偏好下仅手动切换。每屏共用同一占位空间以避免下面内容跳动。

界面风格复用项目现有深蓝工作台；参考已阅读的 Linear features（https://linear.app/features ，访问日期 2026-11-14）中克制的产品信息层次，不迁移其产品能力或宣传效果。产品口径沿用此前阅读的 https://www.zhama.com/zh 与 https://docs.zhama.com.cn/，以及本项目当前源码；外部案例不作为 TeGo 能力验证。

第二屏由原生文字、图表与独立 HTML 报表组成，不使用图片承载关键数字。金额统一万元，三类期末持仓合计 12,863.42，当月赎回合计 472.80，两者比值 3.68%，混合类赎回占比 37.53%。页面与可下载文件共用同一业务数据源。此组数值为用户所需经营场景设计，不是导入的客户记录。当前展示为成果可下载并准备转发，不触发真实 IM 消息。

第三屏约 4.5 小时对比约 12 分钟的经营报表口径由用户提供并于 2026-11-14 明确要求展示。专业内容与发布审核由人工负责。未添加客户实测或客户授权标记。

配图用用户指定的 gpt-image-2 图片 API 生成。V1.0 仅为历史生成记录，因使用横条代替正文而被用户拒绝，未纳入新交付。采用 V1.1 中英文完整业务内容图。提示词与原图在 `output/imagegen/hero-outcomes*V1.1*`，发布图片在 `public/images/hero/business-outcomes-{zh,en}_V1.1.webp`。源文件版本保留；不在网站展示骨架图、加载横条或伪文字。
