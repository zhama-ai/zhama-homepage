# 政务、央国企与企业通用官网文案来源底稿 V1.0

日期：2026-11-19。用途：内部内容审查，不在网站中渲染。

## 阅读范围与使用方法

完整阅读三份指定行业大纲，提取政务、央国企业务和技术架构 HTML 的可见业务正文，并阅读全行业架构图总览。大纲内的制作指令、取证计划、历史运行记录及同业采购事实不转换为官网客户成果。网络研究沿用用户给定材料中的来源索引，本轮未将同业建设事实归属为本平台实施案例。

文案以业务问题、企业收益、平台承接方式和可用成果组织。所有制与垂直行业分开；央国企采用集团经营管理场景，不覆盖或承诺直接控制生产系统。企业通用采用已有平台能力与企业方法，不新增独立垂直行业。

## 政务来源映射

- 政策精准服务：政务业务全景图“政务咨询与政策服务”，结合大纲的权威知识、政策时效和持续维护机制。表述为政策适配和服务支持，不将推荐等同正式资格认定。
- 高效办成一件事：业务图“事项申报与材料预审”“行政审批与协同办理”，大纲 M18 事项情形与材料清单。侧重跨部门服务接续；现有系统通过授权接口衔接。
- 12345诉求治理：业务图“热线诉求与工单服务”“基层治理与网格协同”，对应诉求归类、职责匹配、办理质检和共性问题分析。
- 机关作业与基层减负：业务图“公文会议与督查督办”“财政采购与资产管理”，大纲 M19—M21 采购核查、机关任务及政策维护。将具体执行机制转换为办文、采购、会议和督办价值。
- 部署：大纲 M09—M10，保留区域统筹资源复用、获准云/本地环境、职责授权、知识更新和运行管理，不声称已取得认证、已接通特定政务系统或法定审批自动化。

## 央国企来源映射

- 经营与司库：业务图“战略经营与国资监管”“财务资金与资产管理”，大纲 M10 集团共用层、M25 财务经营与技术架构的集团语义和报送口径。采用穿透视野和分析支撑，不声称自动取得全部集团数据。
- 采购与履约：业务图“招标采购与供应链”“工程项目与合同履约”，大纲 M23。采购方审查与投标方响应分开表达，合同形成后接续履约与供应协同。
- 项目与EHS：业务图“工程项目与合同履约”“生产运维与安全环保”，技术图中项目、资产、安环连接。重点是资料、反馈、偏差分析和团队协作，不写直接自动控制设备或自动消除风险。
- 监督整改：业务图“法务合规与审计监督”，大纲 M24、M26。强调责任单位、证据与后续改进，不冒称审计认定或虚构销号结论。
- 部署：大纲 M11—M13，保持集团资源统筹、单位差异配置、共用方法复用、版本与运行治理，不声称全部所属企业已接入或全栈认证。

## 企业通用来源映射

- 客户经营：企业通用大纲 M09、M23 的销售与项目协作，结合当前既有 CRM 与业务插件能力。CRM 采用“获准资料与能力”的正文表述，不扩展成已完成全行业系统适配。
- 知识与岗位方法：M14—M16，区分知识依据、岗位技能与工作经验，突出团队复用和长期维护。
- 方案与项目交付：M17、M23，以当前可编辑 Word、Excel、PPT 和项目话题、任务、文件版本承接，不用空白原型或取证计划冒充已交付客户成果。
- 经营与周期工作：M18、M24，保留报表、指标、周期执行、指定会话投递等产品机制，聚焦管理价值；不使用同业量化绩效。
- 部署：M10—M12 和两类行业技术架构的共用平台能力；通用导航保持原有 general 类别，仅在方案总览及详情发现，不新增首页行业 Tab。

## 结构与用词检查

三行业中英文均为：2行Hero、4个来源、4个成果、6项场景、3项首页价值、4个详情模块、每模块3项业务成果、6个岗位。每个岗位3项技能、3项过程、2项产出。

中文模块标题14—17字，痛点39—44字，正文92—106字。均未添加排名、客户Logo、实测提效数字、认证或商业案例；不以重复免责声明替代业务介绍。
